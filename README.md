# Eloy Alcala — Portfolio de AI Engineering & Data Science

Portafolio digital de alto impacto interactivo para **Eloy Alcala**, especializado en **Sistemas Multi-Agente, LLMOps, RAG y Ciencia de Datos**.

## 🚀 Despliegue en Producción (100% Gratis)

### Opción 1: Vercel (Recomendada)
1. Sube este proyecto a tu GitHub: `https://github.com/Elocss/portfolio`
2. Ve a [vercel.com](https://vercel.com) e inicia sesión con tu cuenta de GitHub.
3. Haz clic en **"Add New Project"** y selecciona el repositorio de tu portafolio.
4. Framework Preset: **Vite** (se detecta automáticamente).
5. Haz clic en **"Deploy"**.
6. ¡En 30 segundos tendrás tu URL pública profesional (ej. `eloy-alcala.vercel.app`)!

### Opción 2: Netlify
1. Ve a [netlify.com](https://netlify.com) y conecta tu repositorio de GitHub.
2. Build command: `npm run build`
3. Publish directory: `dist`
4. ¡Listo con URL gratuita `*.netlify.app`!

---

## 🛠️ Comandos Locales
```bash
# Instalar dependencias
npm install

# Servidor de desarrollo
npm run dev

# Compilar para producción
npm run build
```
